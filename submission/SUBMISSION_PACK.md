## Accurate product description

ClearTrace is a review-first data quality workspace. It inspects data, explains detected issues, offers suggested repairs for human review, records approved changes, revalidates the dataset, and exports cleaned data and audit information. It supports CSV and spreadsheet workflows, deterministic issue checks, mathematical validation, revision history, comparison, and a mobile PWA shell.

The current hosted demo uses a **shared access token**, not individual user accounts. It does not provide per-account login alerts. Email and SMS alert delivery depends on external provider configuration. Do not describe those items as fully operational in a pitch unless separately configured and verified. The deployed demo is intended for synthetic/sample data, not confidential customer data.
