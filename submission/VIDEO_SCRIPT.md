# ClearTrace — 3-minute demo video script

**Target runtime:** 2:40. Record in one continuous screen capture if possible. Use the synthetic sample dataset only.

### 0:00–0:18 — Hook

“Messy data is easy to clean badly. ClearTrace makes each issue reviewable, every repair deliberate, and every approved change traceable. We built it for Problem 01: DataFix.”

### 0:18–0:40 — Import and context

Show the ClearTrace workspace on a phone or 390-pixel preview. Open the import/workspace module and load the included synthetic quality-issues CSV. Point out that sample data is being used and dataset processing is session-oriented.

“A team can bring in a dataset, see what ClearTrace found, and understand why each item needs attention.”

### 0:40–1:15 — Detect and explain

Open Data Observatory. Show the finding filters and explain one missing value and one invalid date. Mention a statistical outlier as a signal for review, not proof of an error.

“ClearTrace separates detectable defects from decisions that need domain knowledge. It does not invent a missing email or silently delete a surprising salary.”

### 1:15–1:50 — Repair approval

Open Repair Studio. Select a safe, obvious whitespace or category-normalization suggestion. Show the before/after diff and the proposed action. Edit if appropriate, then approve the single repair. If the sample does not expose a suitable safe suggestion, use the UI's sample/workflow designed for an actual suggested edit; do not pretend a disabled or absent control worked.

“The reviewer can edit, approve, or reject. The original stays available, and the change is recorded only after approval.”

### 1:50–2:15 — Revalidate and trace

Re-run the scan. Open the audit ledger or Time Machine and show the resulting revision/change record. Use comparison to show the before/after effect.

“After the change, ClearTrace rechecks the data and preserves the decision trail so another person can review what changed.”

### 2:15–2:35 — Export and mobile

Show an export option, then navigate with the phone bottom bar or module sheet. Keep export sample-only.

“The team can export the cleaned dataset and findings. The responsive PWA can be added to a phone's home screen; dataset operations still need a connection.”

### 2:35–2:45 — Close

“ClearTrace: every issue explained, every fix traceable. Review first. Repair with confidence.”

## Recording checklist

- Keep the video at or below three minutes.
- Use synthetic data; hide browser address-bar tokens, Railway secrets, email accounts, terminal history, and personal notifications.
- Verify every shown action works before recording. Do not stage results or claim a feature that is not configured.
- Add captions or clear narration, then post the video to LinkedIn and test the public/share visibility.
