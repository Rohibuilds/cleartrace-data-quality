# ClearTrace

**Every issue explained. Every fix traceable.**

ClearTrace is a review-first data quality workspace for Problem 01: DataFix. It detects CSV and spreadsheet issues, explains findings, proposes repairs, and records human-approved changes with an audit trail.

- CSV and spreadsheet workflows with deterministic issue checks
- Edit, approve, or reject suggested repairs before mutation
- Revalidation, revision comparison, undo history, and audit exports
- Mobile-friendly Progressive Web App shell

See the project source and local run instructions as files are added. The hosted demo uses a shared access token, not individual accounts; use synthetic data only. Email/SMS delivery depends on provider configuration.

**Demo:** https://cleartrace-web-production.up.railway.app/

**Problem:** Problem 01 — DataFix: Autonomous Data Quality and Repair Engine.
